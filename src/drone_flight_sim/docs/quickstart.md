# 快速开始

## 运行步骤

### 1. 启动仿真环境

- 启动 AirSimNH.exe
- 选择"否(N)"进入四旋翼无人机模式
- 等待仿真环境完全加载

### 2. 运行程序

```bash
python main.py
```

### 3. 选择飞行模式

- 输入 `1`：自动航点飞行模式
- 输入 `2`：键盘手动控制模式

### 4. 键盘控制模式操作

| 操作 | 按键 |
|------|------|
| 水平移动 | W / S / A / D |
| 升降 | Q / E |
| 切换速度档位 | 1 - 5 |
| 一键返航 | R |
| RGB拍照 | P |
| 全景拍照 | T |
| 深度图像 | N |
| 实时预览 | B |
| 退出并降落 | ESC 或 L |

## 照片存储

运行后拍摄的图片会自动保存到 `drone_images/` 目录下，文件命名格式：

| 类型 | 格式 |
|------|------|
| RGB 图像 | `rgb_YYYYMMDD_HHMMSS_X_Y_n序号.png` |
| 深度图像 | `depth_YYYYMMDD_HHMMSS_X_Y.png` |
| 分割图像 | `seg_YYYYMMDD_HHMMSS_X_Y.png` |

其中 `X`、`Y` 为拍照时的无人机坐标，`序号` 为该次运行的第 N 张照片。
