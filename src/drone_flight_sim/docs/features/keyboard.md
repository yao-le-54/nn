# 键盘控制

## 控制按键

| 按键 | 功能 |
|------|------|
| W | 前进 |
| S | 后退 |
| A | 向左横移 |
| D | 向右横移 |
| Q | 上升 |
| E | 下降 |
| 空格 | 悬停 |
| 1-5 | 切换速度档位（慢/中/快/很快/极速） |
| R | 一键返航 |
| L | 执行降落 |
| ESC | 紧急停止并退出 |
| O | 一键环绕（飞矩形轨迹） |

## 特点

- 持续按键时无人机持续移动
- 释放按键后自动悬停并显示移动距离
- 支持组合按键实现斜向飞行

## 速度档位（1-5键）

| 档位 | 速度 |
|------|------|
| 1档（慢速） | 1 m/s |
| 2档（中速） | 2 m/s（默认） |
| 3档（快速） | 3 m/s |
| 4档（很快） | 5 m/s |
| 5档（极速） | 8 m/s |

## 一键返航（R键）

- 自动飞回起飞点位置
- 到达后自动降落
- 起飞时会自动记录返航点
