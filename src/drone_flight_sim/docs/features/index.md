# 功能实现

## 自动连接与初始化

- 自动连接 AirSim 仿真环境
- 获取无人机控制权并解锁电机
- 初始化碰撞检测系统
- 初始化相机系统

## 智能起飞控制

- 自动起飞至指定高度（默认3米）
- 起飞超时保护（10秒）
- 起飞状态验证与反馈

## 定点巡航

- **智能碰撞检测与自动恢复**：实时监测碰撞事件，自动过滤地面/道路接触，碰撞后自动后退避障（最多3次），失败后手动接管
- **大范围航点飞行**：预设11个航点，飞行高度5米

## 多模式相机拍照

| 按键 | 功能 | 说明 |
|------|------|------|
| P | RGB拍照 | 拍摄彩色图像，自动保存 |
| T | 全景拍照 | 一次性拍摄 RGB + 深度 + 分割三种图像 |
| N | 深度图像 | 拍摄深度图（伪彩色：蓝=近，红=远） |
| B | 实时预览 | 打开相机预览窗口，实时查看无人机视角 |

## 键盘手动控制

| 按键 | 功能 |
|------|------|
| W/S/A/D | 前进/后退/左移/右移 |
| Q/E | 上升/下降 |
| 空格 | 悬停 |
| 1-5 | 切换速度档位（1~8 m/s） |
| R | 一键返航 |
| L | 执行降落 |
| ESC | 紧急停止并退出 |
| O | 一键环绕（飞矩形轨迹） |

## 安全降落系统

- **三重降落机制**：正常降落 API → 重试（最多3次）→ 强制复位
- **慢速平稳降落**：以 1m/s 下降速度缓慢降落，实时高度监控
- 降落完成后自动锁定电机
